# 모닝페이지 스레드 운영 정리

## 1. 계정 방향

- **무엇을 하는 계정인가**: 모닝페이지(아침에 머릿속을 쏟아내는 습관)를 알리는 계정
- **최종 목표**: 말로 하는 모닝페이지 앱을 만들어서 판매
- **꼭 전하고 싶은 말**: **"손글씨가 귀찮으면 메모장도 괜찮다. 말로 해도 된다."**
  - 핵심은 손글씨가 아니라 아침에 머릿속을 한 번 쏟아내는 것
  - 원래 『아티스트 웨이』는 손으로 쓰라고 권한다는 건 부정하지 않기
    → "원래는 손으로지만, 귀찮아서 안 하는 것보단 메모장·말로가 낫다"
- **앱은 아직 홍보하지 않기**: 지금은 이 생각에 공감하는 사람을 모으는 단계. 앱이 나오면 "그래서 만들었어요"로 연결

## 3. 정보성 글 공식

### 본글 4단 (각 2~3줄)

1. **첫 마디**: 대상을 부르는 말. 구조는 같고 **말 거는 방식만 매일 바꾸기** (아래 표, 7일 안에 겹치지 않게)
2. **흔한 오해 깨기**: 다들 하는 방법이 왜 안 되는지 단호하게
3. **진짜 이유**: 원리 1~2문장
4. **예고**: 방법 개수를 **꼭 숫자로** — "딱 3가지만 따라 해봐!"
   - "이것만", "이대로"처럼 숫자 없는 예고는 쓰지 않기

### 첫 마디 형식 (돌려 쓰기)

| 형식 | 예시 |
|---|---|
| 명심해형 | "자기 전엔 걱정 때문에 뒤척이는 사람들은 명심해." |
| 질문형 | "3일 쓰고 서랍에 넣어본 적 있어?" |
| 장면형 | "노트 펴고, 펜 들고, 날짜 쓰고. 그리고 5분째 빈 종이만 보는 중." |
| 나만 그래 공감형 | "'아침 루틴' 영상 보면 딴 세상 얘기 같은 거 나만 그래?" |
| 위로형 | "일주일 만에 그만뒀다면 그거 의지 문제 아님." |
| 손 들어형 | "다시 읽어봤다가 유치해서 이불 찬 사람 손🙋" |
| 단정 선언형 | "주말 내내 누워 있었는데 더 지쳤다면 그건 쉰 게 아니야." |
| 비교형 | "아침에 폰 먼저 보는 사람 vs 노트 먼저 여는 사람" |

- 예고 문장 끝맺음도 돌려 쓰기: 따라 해봐 / 바꿔봐 / 기억해 / 끼워 넣어봐 / 하면 돼 / 지켜 / 챙겨봐
- 일상글도 같은 시작 방식을 일주일 안에 반복하지 않기 (정체 밝히기, 장면 나열, 대조, 목록, 질문 등)

### 답글 (방법)

1. 예고에서 말한 숫자와 **정확히 같은 개수**로 `1. 2. 3.` 번호 붙이기 (기본 3가지)
2. 덧붙일 팁은 번호를 늘리지 말고 해당 번호 아래 `(📌 ...)` 한 줄로
3. 기간·분량은 구체적으로 (예: "4주 동안은 다시 읽지 말고 덮기")
4. 마지막은 한 줄 정리 + 가볍게 대답할 수 있는 질문

## 4. 일상글 공식: "A가 B를 한다"

- **A** = 매일 아침 머릿속을 쏟아내는 나 (정체를 밝혀도, 숨겨도 됨)
- **B** = 아침 루틴 / 기분·감정 / 추천템 (모닝페이지 얘기가 아니어도 됨)
- 가르치지 않기. 그 사람이라서 보이는 장면 하나를 툭 던지기
- 질문으로 끝낼 필요 없음. **마지막 반전 한 줄**이 더 중요

### 유형 3가지

| 유형 | 구조 | 참고한 글 |
|---|---|---|
| 정체 + 관찰 + 반전 | 첫 줄에 정체 → 그 사람만 아는 관찰 → 마지막에 살짝 비틀기 | 소아치과 "결국.. 반지에서 나오더군요" |
| 정체 숨기고 장면만 | 장면 → 솔직한 감정 한 줄 → 엉뚱한 혼잣말 | 소아치과 "우리 친하잖아.." |
| 추천템 | 본글: 이유 한 줄 → 산 계기·곳 → 제품명 → "솔직 후기는 👇" / 답글: 수다처럼 후기 → 추천 요청 + 요즘 취향 | 사과유자차 글 + 직접 올린 바디로션 글 |

### 추천템 글 기준 (직접 고쳐서 올린 글에서 정한 것)

1. **음슴체**로 가볍게 (~임, ~함, ~사볼라함). "조아짐", "~는딩", "ㄴㄴㄴ" 같은 말투도 조금 OK
2. 들은 얘기는 솔직하게 + 그 팬들에게 말 걸기: "(아닐 수도 있는데 몬엑팬이면 알려주고가....🙏)"
3. 후기는 이모지 목록 말고 **수다처럼 문단으로**
4. 감각은 구체적으로: "옷에도 은은하게 배서", "바닐라+케이크 같은데 어른 바닐라 느낌??"
5. 아쉬운 점 + 원래 뭘 기대했는지: "극!! 달달달한거를 하나 들이고 싶었는딩"
6. 같이 쓰는 물건, 다음에 사볼 것: "난 세타필 같이 써주는 중", "담엔 스트로베리 사볼라함"
7. 마지막 추천 요청에 **요즘 취향을 구체적으로**: "요새는 구아망드 계열 달달하게 끌림" → 댓글로 추천하기 쉬워짐
8. 주제 태그 달기 (예: 바디로션)

## 5. 쓰지 않는 것

- 호칭 "치니들", "너네" → **"사람들"**로
- 매번 "명심해"로 시작하기 (첫 마디 형식 돌려 쓰기)
- 해본 적 없는 경험, 경력, 물건을 1인칭으로 지어내기
  - 일상글의 사실은 `data/persona.md`(나, 아침 루틴, 추천템)와 `data/notes.md`(있었던 일)에 적힌 것만
  - 추천템은 실제로 쓰는 물건만
- 연구 결과·수치·효과 기간을 사실처럼 쓰기 ("3주면 바뀐다" 등)
- "치료된다", "의학적으로" 같은 단정
- "히든 비법", "100% 효과" 같은 과장
- "내가 수십 번 말했지"처럼 하지 않은 과거 발언
- 링크, "댓글 달아주세요" 같은 대놓고 하는 부탁
- 앱 이름, 다운로드 언급 (출시 전까지)
