# 스레드 글 (복사해서 예약 게시용)

정보성은 **본글을 올린 뒤, 그 글에 답글로** 두 번째 칸을 달아주세요.

일상글은 **초안**이에요. 실제 내 아침과 다르면 고치거나 빼고 올려주세요.


## 1번째 날

### 정보성 — 모닝페이지는 일기가 아니다

**본글**

```
새해마다 다이어리 사놓고
3일 쓰고 서랍에 넣고
빈 페이지 볼 때마다 죄책감 드는 사람들은 명심해.

예쁘게, 의미 있게 쓰려고 하면
그건 숙제가 돼서 오래 못 가.

일기는 하루를 '정리'하는 거라 잘 쓰고 싶어지는데
모닝페이지는 머릿속을 '비우는' 거라 못 써도 돼.
목적이 다르니까 쓰는 법도 달라야 해.

딱 3가지만 바꿔봐!
```

**답글**

```
1. 저녁 말고 아침에 쓰기
2. 하루 요약 말고, 지금 떠오르는 거 아무거나
(📌날짜만 적고 바로 시작)
3. 꾸미기·스티커·예쁜 글씨 다 빼기

잘 쓴 날도 못 쓴 날도 그냥 '쓴 날'이야.
다들 다이어리 몇 권째 서랍에 있어?
```

### 일상글 — 아침 루틴 (정체 + 관찰 + 반전)

```
아침 루틴 만들겠다고
물 한 잔, 스트레칭, 명상, 영양제, 독서, 모닝페이지
다 해봤습니다.

나머지는 의욕 넘치던 시절의 저에게 맡기겠습니다.
```

```
3. 그래도 막히면 "오늘 제일 신경 쓰이는 건…"으로 시작
```

## 4번째 날

### 정보성 — 왜 손글씨인가

**본글**

```
생각나는 건 전부 폰 메모장에 쓰고
타자로 치면 빠른데 왜 손으로 쓰냐고
생각하는 사람들은 명심해.

빨리 쓰는 게 목적이 아니야.

타자는 쓰다가 지우고 고치기가 너무 쉬워서
자꾸 '잘 쓴 문장'을 만들게 돼.
손으로 쓰면 고치기 귀찮아서 그냥 흘려보내게 되고
그게 모닝페이지가 원하는 상태야.

손글씨 처음이면 딱 3가지만 챙겨!
```

**답글**

```
1. 비싼 노트 말고 막 써도 안 아까운 노트
2. 손 덜 아픈 부드러운 펜
(📌글씨 예쁘게 쓰려고 하지 않기)
3. 알림 꺼두고 폰은 다른 방에

다들 노트 줄 있는 거 써, 없는 거 써?
```

### 일상글 — 아침 루틴 (정체 숨기고 장면만)

```
알람 끄고 노트 펴는 데까지 성공했다.
펜 뚜껑도 열었다.
날짜도 적었다.

여기까지가 오늘 아침의 최선이었다.
나머지 3쪽은 내일의 내가 쓰는 걸로.
```
