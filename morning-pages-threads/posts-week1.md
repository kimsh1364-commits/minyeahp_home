# 1주일치 스레드 글 (복사해서 예약 게시용)

정보성은 **본글을 올린 뒤, 그 글에 답글로** 두 번째 칸을 달아주세요. 일상글은 본글 하나입니다.


## 1일차

### 오전 7시 · 정보성 — 모닝페이지 기본 방법

**본글**

```
아침마다 머리가 멍하고
할 일은 많은데 손에 안 잡히고
자기 전엔 걱정 때문에 뒤척이는 사람들은 명심해.

플래너에 할 일만 빼곡히 적어봤자
머릿속 소음은 그대로야.

생각이 정리가 안 되는 건 의지가 약해서가 아니라
머릿속에 쌓인 말이 나갈 데가 없어서야.
종이에 먼저 다 쏟아내야 비로소 자리가 생겨.

딱 이것만 따라 해봐!
```

**답글**

```
1. 눈 뜨자마자 폰 보기 전에 노트부터 펴기
2. 손으로, 생각나는 대로 3쪽 (부담되면 1쪽부터)
3. 문장이 이상해도, 같은 말 반복해도 그냥 계속 쓰기
4. 다 쓰면 다시 읽지 말고 덮기

이게 『아티스트 웨이』에 나오는 '모닝페이지'야.
다들 아침에 제일 먼저 하는 게 뭐야?
```

### 오후 9시 반 · 일상글 — 오늘 아침 첫 문장

```
모닝페이지 첫 문장은
대부분 '졸리다'로 시작한다는 거
써본 사람들은 다 알 거야.

오늘 아침 첫 문장 뭐였어?
한 줄만 남기고 가.
```


## 2일차

### 오전 7시 · 정보성 — 모닝페이지는 일기가 아니다

**본글**

```
새해마다 다이어리 사놓고
3일 쓰고 서랍에 넣고
빈 페이지 볼 때마다 죄책감 드는 사람들은 명심해.

예쁘게, 의미 있게 쓰려고 하면
그건 숙제가 돼서 오래 못 가.

일기는 하루를 '정리'하는 거라 잘 쓰고 싶어지는데
모닝페이지는 머릿속을 '비우는' 거라 못 써도 돼.
목적이 다르니까 쓰는 법도 달라야 해.

일기에 지친 사람은 이렇게 바꿔봐!
```

**답글**

```
1. 저녁 말고 아침에 쓰기
2. 하루 요약 말고, 지금 떠오르는 거 아무거나
3. 꾸미기·스티커·예쁜 글씨 다 빼기
4. 날짜만 적고 바로 시작

잘 쓴 날도 못 쓴 날도 그냥 '쓴 날'이야.
다이어리 몇 권째 서랍에 있어?
```

### 오후 9시 반 · 일상글 — 커피 먼저 vs 모닝페이지 먼저

```
아침에 커피 먼저 내리는 사람이랑
노트 먼저 펴는 사람으로 나뉜다던데

커피 먼저 vs 노트 먼저
다들 어느 쪽이야?
```


## 3일차

### 오전 7시 · 정보성 — 쓸 말이 없을 때

**본글**

```
노트 펴놓고 펜 들었는데
첫 줄부터 막혀서
5분째 빈 종이만 보고 있는 사람들은 명심해.

쓸 말이 떠오를 때까지 기다리면
그날은 한 줄도 못 써.

모닝페이지는 쓸 말이 있어서 쓰는 게 아니라
쓰다 보면 쓸 말이 나오는 거야.
손이 멈추는 순간 머릿속 검열이 시작되거든.

막힐 땐 이것만 해!
```

**답글**

```
1. "쓸 말이 없다"를 그대로 쓰기
2. 지금 보이는 거 적기 (커피 식었다, 창밖 흐리다)
3. 지금 몸 상태 적기 (졸리다, 어깨 뻐근하다)
4. 그래도 막히면 "오늘 제일 신경 쓰이는 건…"으로 시작

멈추지만 않으면 돼.
다들 첫 문장 보통 뭐로 시작해?
```

### 오후 9시 반 · 일상글 — 쓰기 싫은 아침

```
모닝페이지 쓰기 진짜 싫은 아침이 있잖아.

그런 날 3쪽 중 2쪽이
'쓰기 싫다'로 끝나도
그것도 쓴 거야.

다들 쓰기 싫은 날 어떻게 버텨?
```


## 4일차

### 오전 7시 · 정보성 — 출근 전 시간 없는 직장인 루틴

**본글**

```
알람 세 번 끄고 겨우 일어나서
씻고 나가기 바쁘고
'아침 루틴'은 남 얘기 같은 사람들은 명심해.

시간 날 때 써야지 하면
그 시간은 영영 안 와.

모닝페이지는 시간을 '만들어서' 쓰는 게 아니라
이미 하는 일 사이에 '끼워서' 쓰는 거야.
완벽한 아침이 아니어도 돼.

바쁜 사람은 이렇게 해봐!
```

**답글**

```
1. 노트랑 펜을 전날 밤 머리맡에 두기
2. 3쪽 대신 타이머 15분
3. 출근 지하철에서 쓰는 것도 인정
4. 못 쓴 날은 점심 먹고 5분이라도

0쪽보다 반쪽이 훨씬 나아.
다들 출근 준비 몇 분 걸려?
```

### 오후 9시 반 · 일상글 — 펜 vs 연필

```
모닝페이지 쓰는 사람들
펜파야 연필파야?

펜은 못 지워서 좋고
연필은 사각거리는 소리가 좋고.

쓰는 도구 하나씩만 알려줘.
```


## 5일차

### 오전 7시 · 정보성 — 왜 손글씨인가

**본글**

```
생각나는 건 전부 폰 메모장에 쓰고
타자로 치면 빠른데 왜 손으로 쓰냐고
생각하는 사람들은 명심해.

빨리 쓰는 게 목적이 아니야.

타자는 쓰다가 지우고 고치기가 너무 쉬워서
자꾸 '잘 쓴 문장'을 만들게 돼.
손으로 쓰면 고치기 귀찮아서 그냥 흘려보내게 되고
그게 모닝페이지가 원하는 상태야.

손글씨 처음이면 이렇게 시작해!
```

**답글**

```
1. 비싼 노트 말고 막 써도 안 아까운 노트
2. 손 덜 아픈 부드러운 펜 (중성펜 추천)
3. 글씨 예쁘게 쓰려고 하지 않기
4. 알림 꺼두고 폰은 다른 방에

다들 노트 줄 있는 거 써, 없는 거 써?
```

### 오후 9시 반 · 일상글 — 작심삼일 고백

```
모닝페이지 다시 시작하는 사람들
솔직하게 몇 번째 시작이야?

작심삼일도 열 번 하면 30일이야.
숫자로만 대답해줘.
```


## 6일차

### 오전 7시 · 정보성 — 다시 읽지 않기

**본글**

```
어제 쓴 거 궁금해서 다시 읽어보고
유치하고 부끄러워서
오늘은 펜이 안 나가는 사람들은 명심해.

모닝페이지는 다시 읽는 순간
'누가 볼 글'이 돼버려.

아무도 안 본다고 믿어야
진짜 하고 싶은 말이 나와.
읽을 생각을 하면 손이 알아서 검열하거든.

그래도 궁금하다면 이렇게 해!
```

**답글**

```
1. 처음 몇 주는 절대 다시 읽지 않기
2. 다 쓴 페이지는 바로 넘기거나 접어두기
3. 한참 지나서 읽고 싶으면 한 번에 몰아서
4. 읽을 땐 평가 말고 '자주 나오는 말'만 찾아보기

반복되는 걱정이 보이면 그게 진짜 신호야.
다들 쓴 거 다시 읽는 편이야?
```

### 오후 9시 반 · 일상글 — 오늘 하나만 하고 싶은 것

```
아침에 머릿속 다 쏟아내고 나면
이상하게 '오늘 이거 하나만 하고 싶다'가
하나 남을 때가 있어.

오늘 딱 하나만 할 수 있다면 뭐 할 거야?
```


## 7일차

### 오전 7시 · 정보성 — 아티스트 데이트

**본글**

```
주말에 쉬어도 쉰 것 같지 않고
좋아하는 게 뭐였는지 기억이 안 나고
누가 취미 물어보면 할 말이 없는 사람들은 명심해.

누워서 폰만 보는 건 쉬는 게 아니라
남의 걸 계속 넣기만 하는 거야.

모닝페이지가 머릿속을 비우는 거라면
'아티스트 데이트'는 다시 채우는 거야.
『아티스트 웨이』에서 둘을 짝으로 권하는 이유야.

이번 주에 딱 한 번만 해봐!
```

**답글**

```
1. 일주일에 한 번, 1~2시간
2. 무조건 혼자 가기
3. 생산적인 거 말고 그냥 끌리는 거 (문구점, 낯선 동네 산책, 전시)
4. 사진 찍어 올리기보다 그냥 보기

다들 혼자 가보고 싶은 곳 하나만 말해줘.
```

### 오후 9시 반 · 일상글 — 주말 아침에도 쓰는지

```
평일엔 겨우 쓰는데
주말엔 늦잠 자느라 노트를 못 펴는 사람들 있지.

주말 아침에도 쓰는 사람?
아니면 주말은 쉬는 날?
```
